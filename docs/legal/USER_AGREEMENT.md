# 电视工坊用户协议

更新日期：2026-11-09

本协议说明您使用电视工坊（以下简称“本应用”）时的基本规则。本应用是用于个人技术学习与研究的 Android 直播播放工具，不要求注册账号。使用前请阅读本协议和[隐私政策](PRIVACY_POLICY.md)；如果您不能接受相关规则，请停止使用相应功能或卸载本应用。

## 1. 应用提供的功能

您可以在自己有权使用的 Android 设备上安装、使用和卸载本应用。

本应用提供：

- 频道分类浏览和名称搜索；
- 收藏和最近观看记录；
- 通过订阅地址或粘贴正文导入 m3u / m3u8 列表；
- 第三方直播地址播放、自动换源、有限重试、清晰度选择和设备支持的画中画。

本应用是客户端工具，不运营电视节目服务，不托管、转播或转码节目，也不提供录制、媒体下载或缓存导出功能。播放时仍需要从第三方接收并暂时缓冲音视频。

## 2. 频道来源与内容权利

内置目录参考 fanmingming/live、iptv-org/iptv 和 Guovin/iptv-api 的部分公开列表或历史结果，随应用版本提供，不会在启动时自动同步。部分地址仍缺少可复核的逐条出处；具体范围见[项目来源说明](https://github.com/SiXuManYan/TvWorkshop/blob/main/README.zh-CN.md#内置频道与来源)。

列表整理项目、实际流服务方和节目权利方可能是不同主体。本应用与上述项目、电视台或其他权利方没有官方合作或背书关系。节目、名称、台标和商标等权利归相应权利方所有。

公开可访问、来源署名或“学习研究用途”都不等于获得内容授权。上游列表和软件的许可证也不会自动授予节目使用权。请只播放您有权访问的内容，并遵守内容提供方的条款和适用法律。

## 3. 导入频道列表

您可以粘贴单行 HTTP(S) 订阅地址，或直接粘贴 m3u / m3u8 列表正文。请确认地址来源可信且您有权访问；不要在不必要的情况下提交包含个人信息、账号信息或访问令牌的地址。

导入只保存当次解析出的频道和播放地址，不保存订阅地址用于后续刷新，也不会定时更新。同一批次同名频道会合并线路；与内置目录同名但包含新地址的条目会另存为导入频道，不替换内置目录。已存在的导入记录会被跳过，因此重新导入不保证更新其中的其他线路。

导入频道按名称和分组分类，可能出现在“央视”“卫视”或“外国频道”等分类中，并不全部位于“自定义”。“清空自定义频道”实际删除全部导入频道，但不会同时删除收藏和最近观看记录。

## 4. 播放与可用性

直播地址可能失效、改变、限制地区或运营商，也可能要求 IPv6。频道名称、节目内容、画质和持续可用性取决于第三方服务、网络和设备，本应用不作保证。“主源”“备用”等标签只表示尝试顺序。

播放错误后，应用会尝试后续线路；最后一路失败后延迟重试当前线路，最多两次。您也可以手动重试、换源或切换频道。自动轮换和重试不能保证恢复播放。

本应用不提供普通后台持续播放。离开前台时会释放播放器，回到前台后重新装载当前线路；设备支持的画中画模式可以继续播放。播放和下载可能产生运营商流量费用，请根据网络套餐使用。

## 6. 本地记录、网络和隐私

收藏、最近观看和导入频道由应用保存在本机，不主动上传给开发者。订阅下载和直播播放会直接访问第三方服务器，对方可能收到 IP、请求地址和普通请求头；用户输入地址中的查询参数也可能随请求发送。部分地址使用未加密 HTTP。

应用启用 Android 系统备份，数据库可能按系统设置进入云备份或设备迁移。详细的数据类型、网络请求、备份、清理和第三方边界见[隐私政策](PRIVACY_POLICY.md)。
