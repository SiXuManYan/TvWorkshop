# 电视工坊用户协议

更新日期：2026-11-09

本协议说明您使用电视工坊（以下简称“本应用”）时的基本规则。本应用是一款用于个人技术学习与研究的 Android 直播播放工具。请在使用前阅读本协议及[隐私政策](PRIVACY_POLICY.md)；如无法接受相关规则，请停止使用相应功能或卸载本应用。

## 1. 应用与使用范围

您可以在自己有权使用的 Android 设备上安装、使用和卸载本应用。应用提供频道分类、搜索、收藏、最近观看、频道列表导入与直播播放功能，不要求注册账号。

本应用提供客户端工具，不运营电视节目服务，不托管、转播或转码节目，也不提供录制、媒体下载或缓存导出功能。播放仍需要从第三方接收并缓冲音视频。

## 2. 频道来源与内容权利

内置目录参考 fanmingming/live、iptv-org/iptv 与 Guovin/iptv-api 的部分公开列表或历史结果，随应用版本提供，不在启动时自动同步上游。部分地址仍缺可复核的逐条来源记录，具体核对范围见[项目来源说明](https://github.com/SiXuManYan/TvWorkshop/blob/main/README.zh-CN.md)。

列表整理项目、实际流服务提供方和节目权利方可能是不同主体。本应用与上述项目及电视台没有官方合作或背书关系。节目、名称、商标等权利归各自权利方所有。

公开可访问、来源署名以及学习研究用途均不等于取得内容授权；上游列表或软件的许可证也不自动授予节目使用权。请只播放您有权访问的内容，并遵守内容提供方的条款及适用法律。

## 3. 导入频道列表

您可以粘贴 HTTP(S) 订阅地址，或直接粘贴 m3u / m3u8 列表正文。请确认地址可信、内容可合法访问，并避免提交包含不必要个人信息或敏感凭据的地址。

导入保存当次解析的频道和播放地址，不会定时刷新订阅，也不保存订阅地址作为后续刷新入口。同一批次同名频道会合并线路；与内置目录同名但包含新地址的频道会另行保存，不替换内置目录。已有导入身份会被跳过，重新导入不保证更新其其他线路。

导入频道会按名称与分组分类，可能出现在“央视”“卫视”或“外国频道”等分类。“清空自定义频道”实际删除全部导入频道，不同时清除收藏和观看记录。

## 4. 播放与可用性

直播地址可能失效、变更、限制地区或运营商，也可能要求 IPv6。频道名称、节目内容、画质与持续可用性由第三方及设备条件决定，本应用不作保证。“主源”“备用”等标签只表示尝试顺序。

播放报错后，应用会尝试后续线路；最后一路失败后进行有限自动重试。您也可以手动重试、换源或切换频道。自动轮换和重试不能保证恢复播放。

本应用不提供普通后台持续播放；离开前台会释放播放器，返回后重新装载当前线路。设备支持的画中画模式可以继续播放。网络使用可能产生运营商流量费用，请根据自己的网络套餐使用。

## 5. 使用规则

- 遵守适用法律与内容服务条款，不利用本应用绕过付费、账号、地区或其他访问控制。
- 不导入或传播您无权访问、使用的内容，不侵害他人的知识产权、隐私或其他合法权益。
- 合理使用第三方服务，避免恶意请求、批量滥用或干扰其正常运行。
- 不以本应用的名称、界面或来源说明暗示获得电视台、节目权利方或列表项目的授权与背书。

## 6. 本地记录与隐私

收藏、最近观看与导入频道由应用保存在本机，不主动上传给开发者。订阅下载与直播播放会直接访问第三方服务器，对方会接收到 IP、请求地址等网络信息。部分地址使用未加密的 HTTP，用户地址中的令牌等参数也可能随请求发送。

应用启用 Android 系统备份，数据库可能按系统设置进入云备份或设备迁移。详细处理范围、清理方式与第三方边界见[隐私政策](PRIVACY_POLICY.md)。

本项目的学习用途说明不构成对源码的任意复制、再分发或商业使用授权。源码许可及第三方声明应以对应项目实际发布的许可文件为准；组件与来源链接可在[项目说明](https://github.com/SiXuManYan/TvWorkshop)中查阅。
