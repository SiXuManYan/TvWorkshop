# 电视工坊版本更新日志

当前源码版本为 1.0。本页记录面向用户的功能与体验变化，随安装包提供，可离线阅读。“开发中”表示尚未登记为新发布的改动，文档日期不代表安装包发布日期。

## 开发中｜2026-11-09

### 新增版本与协议页面

- “关于”升级为独立页面，显示当前安装构建的版本，集中提供版本更新日志、用户协议、隐私政策和频道来源说明。
- 三份文档提供简体中文离线阅读，支持章节定位、滚动高亮和回到顶部；版本日志逐项展开或收起时，正文与箭头同步过渡，连续点击可反向接续，章节定位在动画完成后执行。
- 协议与隐私政策说明第三方直播内容、导入列表、本地记录、网络请求和 Android 系统备份的实际边界。

### 播放、浏览与导入修正

- 快速连续换台按最新操作目标继续切换，频道已不存在时停止播放旧视频。
- 换源后不再保留无效的清晰度限制，返回前台或退出画中画后恢复操作区。
- 调整收藏连续点击的状态同步，将频道筛选移到后台处理。
- 修正多行裸地址的导入识别、地址校验与字符集处理，保留线路顺序并减少重复导入的额外处理。

### 界面与操作体验

- 播放页集中保留上一频道、频道列表、下一频道和播放设置，设置中可直接选择线路、画质和画中画，无需横向寻找按钮；错误提示与操作支持在短窗口内滚动查看。
- 顶底栏改用边缘渐隐遮罩，3 秒无操作后轻移淡出；换台提示只在操作区隐藏时短暂出现在顶部边缘，减少画面遮挡。系统栏可由屏幕边缘滑动临时唤出。
- 使用键盘、遥控器或读屏操作时保持控件可见，方向键可以唤出隐藏的操作区，并提供清楚的焦点提示。
- 主页空态在工具栏下方展示并避让键盘，重建页面后保留列表位置；频道名称与摘要更适合大字体显示。
- 导入框分开显示简短标签与说明，长列表在输入区内滚动，方便保留和修改正文。
- 频道列表改为与视频分区显示，宽窗口并排、窄窗口上下排列，选台时不遮住视频；首次定位当前频道，搜索支持清空与收起键盘。点选、关闭、返回或点击视频均恢复全屏，页面重建保留查询和列表位置，读屏可识别正在播放的频道。
- 关于页的文档入口增加分隔，收藏和清晰度操作的读屏描述补充频道名或当前模式。

### 内置信号源清理

- 根据实际内容抽样，移除 CCTV-2、CCTV-16、广东、山东、山西、宁夏、陕西共 7 路曾返回错配购物节目的地址，保留 66 个频道、162 个播放地址，并整理剩余线路标签。
- 本次只更新随包内置目录，用户已导入的频道不受影响；抽样无法保证其余第三方线路始终正确或可用，也不屏蔽电视台节目中的正常广告。

上述为当前开发改动，应用版本号仍为 1.0；尚未登记新的正式发布。实际直播可用性、出画时间和设备表现仍取决于来源、网络及设备，不以本日志作为实测保证。

## v1.0｜基础功能

以下为当前版本的基础能力概览，不补记未经核实的发布日期。

- 分类浏览央视、卫视、外国及自定义频道，提供按名称搜索与最近观看。
- 支持本地收藏，以及通过订阅地址或粘贴正文导入 m3u / m3u8 频道列表。
- 横屏直播播放，支持多线路自动轮换、有限重试、清晰度选择和频道抽屉。
- 双击或横向轻扫换台，提供换台提示与自动隐藏的操作区；支持设备可用的画中画模式。
- 收藏、观看记录与导入频道保存在本机；Android 系统备份可能参与云备份或设备迁移。
