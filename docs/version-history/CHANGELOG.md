# 电视工坊版本更新日志

当前源码版本：`1.0`。

本页记录随安装包展示的功能和体验变化。**“开发中”表示尚未登记为新发布的改动，记录日期不代表安装包发布日期。**

直播可用性、出画时间和设备表现取决于第三方来源、网络和设备，本页不构成实测保证。

## 开发中｜2026-11-11

### 收藏与频道管理

- 主页增加“我的收藏”分类，跨分类集中浏览已收藏频道，支持原有搜索和取消收藏。
- 新增“频道管理”页面，统计导入频道与观看记录，支持搜索全部导入频道、点按播放和确认删除单个导入记录。
- 通过系统文件选择器导入 UTF-8 编码的 m3u / m3u8 文件，无需共享存储权限；仍按原有同名合并、保序去重规则保存。
- 可将全部导入频道导出为 m3u 列表；保存前说明完整地址可能包含令牌。内置频道、收藏和观看记录不在导出范围内。
- 可单独清空全部最近观看记录，保留收藏和导入频道。

### 观看设置

- 播放设置增加完整显示、等比裁切铺满和拉伸铺满，切换模式不重新装载直播。
- 睡眠定时提供 15、30、60、90、120 分钟与关闭，顶栏显示剩余分钟。换台和换源继续计时，到期停止音视频并退出播放页，画中画同样生效。
- 画面模式和定时随当前播放页恢复；到期后返回前台或进程重建不会重新开播。主动退出播放页结束本次设置，不创建系统闹钟或后台服务。
- 新增通用文案同步维护既有 11 个语言目录；相关使用边界同步到协议与隐私政策。

本节尚未登记为新版本发布。当前仅完成源码、资源和文档静态检查，构建、测试、Lint 和设备体验验证未运行。

## 开发中｜2026-11-09

### 关于与离线文档

- 新增独立的“关于”页面，显示当前构建版本，并集中提供更新日志、用户协议、隐私政策和频道来源说明。
- 三份正文随 APK 提供，支持离线阅读、章节定位、滚动高亮和回到顶部。
- 版本卡片可独立展开或收起，正文高度、透明度和箭头同步过渡；连续点击可以从当前动画进度反向接续，章节定位会等待动画和布局稳定。
- 协议和隐私政策说明第三方直播内容、导入列表、本地记录、网络请求和 Android 系统备份的边界。

### 播放、浏览与导入

- 快速连续换台以上一次请求的目标为基准继续计算，频道不存在时会清空旧视频。
- 换源后清理无效的清晰度限制；普通退后台释放播放器，返回前台或退出画中画后恢复操作区。
- 直播进度落后于播放列表保留窗口时，先在当前线路重新接入一次，恢复失败再尝试后续线路；普通缓冲等待不会直接触发换源。
- 起播和卡顿后的缓冲阈值调整为 1.5 秒与 3 秒，为短时网络抖动预留余量，也可能增加等待；实际阈值仍受直播延迟影响，效果待设备验证。
- 调整收藏连续点击的状态同步，并将主页和选台面板的筛选移到后台执行。
- 修正多行裸 URL 的导入识别、HTTP(S) 地址校验和字符集处理；同名线路保留顺序并减少重复导入的额外读取。

### 播放页与频道列表

- 上一频道、频道列表、下一频道和播放设置集中在容易触达的位置；线路、画质和画中画通过设置菜单选择。
- 修正浅色主题下设置菜单白字叠在浅底上的问题，根菜单和子菜单统一使用深色背景与浅色文字。
- 顶底栏使用边缘渐隐遮罩，3 秒无操作后淡出并轻移；操作区隐藏时，换台提示只在顶部边缘短暂显示。
- 系统栏可以通过边缘滑动临时唤出；键盘、遥控器、读屏和错误状态下操作区保持可用。
- 频道列表与视频改为同页分区：宽窗口并排，窄窗口上下排列，不覆盖播放画面。
- 频道面板支持搜索、清空和收起键盘；点选、关闭、返回或点击预览后恢复全屏；页面重建保留查询和列表位置，并标识当前播放项。
- 主页空态位于工具栏下方并避让键盘，频道名称和摘要适配大字体；导入框将短标签与长说明分开，正文在输入区内滚动。

### 内置信号源

- 根据一次内容抽样，移除 CCTV-2、CCTV-16、广东、山东、山西、宁夏和陕西共 7 路曾返回错配购物节目的地址。
- 保留 66 个频道和 162 个播放地址，用户已经导入的频道不受影响；抽样不能保证其他第三方线路长期正确或可用，也不屏蔽电视台节目中的正常广告。

应用版本号仍为 `1.0`，本节尚未登记新的正式发布。

## v1.0｜基础功能

以下是当前版本的基础能力概览，不补记未经核实的发布日期：

- 分类浏览央视、卫视、外国和自定义频道，支持名称搜索和最近观看；
- 本地收藏，以及通过订阅地址或粘贴正文导入 m3u / m3u8 频道列表；
- 横屏直播播放，多线路自动轮换、有限重试、清晰度选择和频道列表；
- 双击或横向轻扫换台，自动隐藏操作区和设备支持的画中画；
- 收藏、观看记录和导入频道保存在本机；Android 系统备份可能将这些数据纳入云备份或设备迁移。
