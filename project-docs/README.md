## 文档放在哪里

- 根目录 `AGENTS.md`：长期开发与审查规范，集中维护，不建大小写不同的副本。
- 根目录 `README.md` / `README.zh-CN.md`：项目入口，中文为主文档；功能、免责与构建说明在此维护。
- `project-docs/`：工程专题（架构、设计与限制），不随 App 打包。新增专题先登记进上表，受影响的入口文档同步链接。
- `docs/legal/` 与 `docs/version-history/`：面向用户的中文离线文档，通过 `app/build.gradle.kts` 的 assets 源目录配置打包；不得混入工程审查记录或未经核实的发布信息。

历史验证明细暂未建立独立需求核对记录；各文档只声明当次实际检查范围，历史通过结论不自动覆盖后续差异。
